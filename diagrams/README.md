# Diagrams

Every diagram in this repo is generated by one script, so they all share the
same style and can be changed in code.

```bash
python3 diagrams/build.py
```

It needs only Python 3. To add a diagram, write a function in `build.py` using
the helpers at the top (`group`, `node`, `arrow`, `badge`), call it at the
bottom of the file, and run the script.

## Icons

`icons/` holds the AWS Architecture Icons the script uses, so nothing is
downloaded at build time. The icons are the property of Amazon Web Services,
which publishes them for use in architecture diagrams:
<https://aws.amazon.com/architecture/icons/>. The SVG files were taken from the
[`aws-icons`](https://github.com/MKAbuMattar/aws-icons) package, version 3.3.0
(MIT, see `icons/LICENSE-aws-icons.txt`).

The script copies each icon into the SVG that uses it, because GitHub does not
load external files from inside an SVG image.
